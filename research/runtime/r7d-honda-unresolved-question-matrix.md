# R7D Honda unresolved question matrix

R7D can reduce questions to explicit future target-only experiments; it cannot answer them on an emulator.

| Domain | Unresolved question | R7D classification |
|---|---|---|
| Platform | Does the ARMv7/API17 binary execute on the intended system? | `HONDA_UNKNOWN` |
| Display | Can Display1 be enumerated, Presentation admitted, Surface acquired, and a controlled frame shown? | `HONDA_UNKNOWN` |
| Geometry/safety | What physical region and safe area are affected; do warnings/interrupt layers remain visible? | `HONDA_UNKNOWN` |
| Restoration | Can a separately authorized temporary target execution terminate cleanly? | `HONDA_UNKNOWN` |
| USB/iAP2 | Who can lawfully own the transport and provide genuine MFi authority? | `AUTHORITY_REQUIRED` |
| Real CarPlay | Does `/info` accept the implementation; does SETUP accept Type110/111; what is Type111 framing/security? | `HONDA_UNKNOWN` |
| Audio/controls | How are host audio, controls, and interrupts preserved? | `HONDA_UNKNOWN` |

No R7D emulator result changes these classifications.
