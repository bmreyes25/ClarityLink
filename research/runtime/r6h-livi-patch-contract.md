# R6H LIVI patch contract

Reviewed upstream: `f-io/LIVI` at `dcb78854c59ba621f4d327910dc275da386496b4`, retrieved 2026-10-05. Patch: [`0001-control-delegate-dispatch-and-bounds.patch`](../../third_party/patches/livi/0001-control-delegate-dispatch-and-bounds.patch), SHA-256 `3756b472f4ee07f67dbd4a986055c97df7a2a970a36e6ce8768ee07d57b917d8`.

The patch adds `ControlSessionDelegate` at `CpStackConfig` and intercepts GET paths ending `/info` plus every SETUP method before `_handle`. The claimed request bypasses LIVI stock dispatch. One call to `buildResponse` serializes its result once. A null delegate result returns 503 and closes the socket after writing; exceptions produce the existing single 500 response. Other requests use stock behavior. It adds a framed Node Unix-socket client, environment wiring through `CpSession`, and an auth transition emitted only after MFi `/auth-setup` response write, successful `PairVerify.controlKeys`, and a subsequent control request. Claimed `/info` and all SETUP methods bypass stock `_handle`; nonclaimed requests stay stock. `dispatchAndSerializeControlRequest` and `writeControlResponseOnce` are tested as the single-owner/response oracle. Header/body bounds are 64 KiB/1,000,000 bytes. Pairing IDs, peer addresses, `/info` request bodies, and error text are redacted from affected logs. Focused upstream typecheck and 20 delegate/client/parser tests pass. The wider CpStack test file could not load the native `livi_crypto.node` addon: `pnpm install --ignore-scripts` kept install scripts disabled and `cargo` is not installed.

The patch is a source-only, reproducible LIVI integration. ClarityLink provides the matching Python receiver in `auth_providers/livi_ipc.py` and `tools/r6h_livi_receiver.py`. Host integration uses synthetic frames; hardware/real-phone validation remains pending. Focused typecheck and delegate/IPC/parser tests passed; the broader CpStack tests require the native crypto addon.

## Reproduce or revert

From a clean checkout of the pinned upstream SHA, apply with `git apply 0001-control-delegate-dispatch-and-bounds.patch`; validate with `git diff --check`, `pnpm run typecheck`, and the two focused Vitest files for `controlDelegate` and `rtspMessage`. To revert, run `git apply -R 0001-control-delegate-dispatch-and-bounds.patch`. The patch is source-only; it contains no upstream binary or secrets.
