# R5D negative-evidence controls

- No public search result does not mean a feature is absent.
- No string or exported symbol does not mean code is absent.
- No public binary does not mean no binary exists.
- TBT/cluster metadata does not establish Type111.
- External Type111 prior art does not establish Honda Type111.
- A later Honda receiver does not establish Clarity compatibility.
- Matching version syntax does not establish a common codebase or update branch.
- Matching package filename does not authenticate a mirror.
- An update archive may be partial or delta; missing files cannot be treated as missing from the installed system.
- A bulletin failed-part field is not an inventory of every installed trim's exact head-unit part.
- A package region, model year, trim, supplier and ROM type must each be independently matched before lineage is promoted.
- A literal `111` is not dispatch, response, listener, media, security or teardown evidence.

All unknowns remain explicit in the [closure table](r5d-artifact-provenance-closure-table.md). R3C runtime NO-GO and Rules v2 continue to control.
