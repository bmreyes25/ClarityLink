# Future bounded observation decision

R6D does **not** propose a vehicle observation now. Static code establishes the certificate/signature path and 7-bit configured address; a passive process or fd inventory would not resolve cross-process locking or actual oracle behavior. A live certificate/signature operation would be active authentication and is outside this milestone. The first unresolved boundary should be closed by further offline ABI/error/lifecycle analysis and host stack work. Any later target experiment needs its own exact run plan, safety review and explicit authorization.
