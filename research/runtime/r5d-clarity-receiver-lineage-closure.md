# R5D Clarity receiver lineage closure

## Preserved target identity

Project-preserved static records identify the 2018 Clarity target as `Honda/Andromeda/vcm30t30a`, model `MY16ADA`, Android 4.2.2 / API 17, Tegra 3 / ARMv7, kernel `3.1.10+`, software build `1.F1A2.45`, and a 13,406,720-byte ARM ELF `jmcs` with SHA256 `cbc7ba881648fb8ffdfcc4c1100a028345c37134a2ae3b9dff7d76572851c232`. The project also preserved `libcarplay_proxy.so` (SHA256 `dc8bc5c19cf32a8e7edcc14c1d80e78bb96ca6ccc434229349c74590136bef66`) and CarPlayService, ExternalDisplay, and navigation evidence. See [kernel/API17 report](../../step-reports/40d-honda-kernel-and-api17-runtime.md), [screen transport study](../carplay/screen-start-transport.md), [identity ledger](../carplay/jmcs-acquisition-identity.md), and [R3C](../../step-reports/43t1-r3c-static-entry-ownership-closure.md). These are target-specific project records, not a public descendant artifact. R3C found no safe supported Type111 runtime entry.

For 2018 Clarity PHEV Touring, the [public OEM parts catalog listing](https://www.hondapartsnow.com/parts-list/2018-honda-clarity_plug_in_hybrid--4dr_trng_clarity_phev-ka_cvt/electrical_exhaust_heater_fuel/audio_unit_audio_navigation.html) labels audio-navigation units `39101-TRW-A74` and `39101-TRW-A75` as Mitsubishi, both replaced by `39101-TRW-A76`. This establishes catalog fitment/supplier for that trim, **not** the exact part number on the preserved unit. Other Clarity powertrains/trims have distinct catalog numbers. Exact target label, firmware packaging, and supplier source revision remain `UNKNOWN`.
