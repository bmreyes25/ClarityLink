**Result:** no `SUPPORTED_STATIC_CANDIDATE` for *Honda compatibility* was established. The API-17 `Presentation` is a public AOSP candidate and the best next static lead, but no preserved Honda evidence shows an ordinary app successfully owns a visible window on Display 1 while Honda warnings retain priority. A full-window overlay is technically plausible in generic API17 with permission, yet its stock-warning risk makes it unsuitable as the project path under current evidence. The verdict is **possible but unproven**, not an install or experiment GO.
