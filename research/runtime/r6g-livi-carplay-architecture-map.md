# R6G LIVI CarPlay architecture map

Source baseline: [LIVI commit `dcb78854c59ba621f4d327910dc275da386496b4`](r6g-livi-source-baseline.md), inspected 2026-10-05. Public source links below are pinned to that commit.

| Layer | Exact source and symbol | Owner / input → output | Lifetime and close path | ClarityLink relevance |
|---|---|---|---|---|
| LIVI Link / helper | `native/livi-helperd`; `CpHelperSock` in `src/main/services/projection/driver/cp/CpHelperSock.ts` | Mac helper ↔ CPC200-CCPA/LIVI Link; local `/tmp/cp-bt.sock` JSON RPC including MFi certificate/sign operations and iAP2/BlueZ event/control functions | Shared by `CpManager`; helper subscriptions and socket close on manager shutdown | Genuine authority and iAP2 side only. No RTSP control request stream exposed by this protocol |
| Shared CarPlay listener | [`CpManager.start`, `_spawn`, `_register`](https://github.com/f-io/LIVI/blob/dcb78854c59ba621f4d327910dc275da386496b4/src/main/services/projection/driver/cp/CpManager.ts) | Accepts control socket; associates helper/iAP2 metadata; creates one `CpSession` | Manager owns listener/helper and closes every `CpSession` | Natural injection/configuration point for a delegate factory, but not yet a control callback |
| Per-phone owner | [`CpSession.attachSocket`, `close`](https://github.com/f-io/LIVI/blob/dcb78854c59ba621f4d327910dc275da386496b4/src/main/services/projection/driver/cp/CpSession.ts) | One accepted socket + helper + seed → one `CpStack`, events and media lifecycle | Session owns stack and closes it on disconnect/manager close | Preserve one socket/session owner; avoid a second receiver |
| CarPlay control transport | [`CpStack.attachSocket`, `_teardown`](https://github.com/f-io/LIVI/blob/dcb78854c59ba621f4d327910dc275da386496b4/src/main/services/projection/driver/cp/stack/cpStack.ts) | Node `net.Socket`; plaintext RTSP until pair-verify, then `ControlCipher` encrypted frames; `parseMessages` → serialized promise chain | `CpStack` owns socket set, private per-connection state and teardown on socket close | This is the only source-confirmed early request/response seam; ClarityLink must route before `_handle` |
| MFi call path | `CpStack._handle` `/auth-setup` → `handleAuthSetup(req.body, this._mfi)`; helper implementation in `CpHelperSock` | Parsed auth-setup body → signer call → opaque response bytes | Same control session; no secret should escape helper | Signer call is not a whole authenticated-session handoff |
| Pairing / encrypted control | `CpStack._handle` `/pair-setup`, `/pair-verify`; `PairSetup`, `PairVerify`, `ControlCipher` | RTSP body → pairing protocol response; pair-verify creates control keys and encrypted session | Per connection; `_teardown` and socket close | LIVI must retain this security/session ownership; adapter sees requests only after LIVI parses/decrypts |
| `/info` dispatch | [`CpStack._handle`](https://github.com/f-io/LIVI/blob/dcb78854c59ba621f4d327910dc275da386496b4/src/main/services/projection/driver/cp/stack/cpStack.ts) and `stack/getInfo.ts` | `RtspRequest` → `buildInfoPlist` → binary plist response | Handler returns to the socket writer in `attachSocket` | Directly competes with ClarityLink today. Must be delegated before stock dispatch |
| SETUP dispatch | [`CpStack._handleSetup`](https://github.com/f-io/LIVI/blob/dcb78854c59ba621f4d327910dc275da386496b4/src/main/services/projection/driver/cp/stack/cpStack.ts) | Binary plist → session timing/event listeners, screen/audio/data stream setup, plist response | Stream owners live in private `CpStack` session; `_teardown` closes them | Delegating SETUP also requires disabling stock side effects. R6G adapter targets control boundary only; no Type111/media claim |
| Screen/audio/data | `CpStack._setupScreen`, `_setupAudio`, `_setupDataStream`, `_closeScreen`, `_closeAudio` | SETUP stream descriptors → native/GStreamer listeners and stream metadata | Per `CpStack` session, closed selectively by TEARDOWN or `_teardown` | If ClarityLink owns Type110/111, stock screen creation must not run for those streams |
| Response serializer | `attachSocket` → `buildResponse(req, await this._handle(...))`; `rtspMessage.ts` | request metadata + `RtspResponse` → RTSP frame, encrypted after pair-verify | Exactly once in socket chain | Delegate should return a response object to this single serializer; do not send a second raw socket response |
| Disconnect | `attachSocket` socket `close` → `_teardown`, session-ended event; `CpSession.close`, `CpManager.close` | EOF/socket error → stream cleanup and session lifecycle notifications | Single manager/session/stack owner | Bridge disconnect must invalidate generation, close handoff and make reconnect allocate a new generation |

**Observed ownership:** LIVI owns transport, pairing/encryption, MFi signer calls, RTSP parsing/serialization and current `/info`/SETUP. There is no documented host API for handing those requests to another receiver. No physical device or session was used in this source audit.
