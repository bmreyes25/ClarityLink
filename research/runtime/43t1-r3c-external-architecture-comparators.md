# 43T1-R3C expanded — external architecture comparators

All receiver comparisons here are `EXTERNAL_PRIOR_ART`, never Honda proof. Links are source/version pinned where available. This is an architecture comparison, not implementation guidance.

| xcertplay | [`shilapi/xcertplay` `17c92439413638dfd1d7f91d7e1c2e7358398762`](https://github.com/shilapi/xcertplay/tree/17c92439413638dfd1d7f91d7e1c2e7358398762), [local differential](../carplay/xcertplay-type111-differential.md) | `/info` can emit separate Type110/111 descriptors. The comparator pattern separates **protocol architecture** (two stream types and independent media state) from **integration architecture** (how an existing production receiver calls project code). xcertplay controls its full receiver. MHI2 reports hooks for production receiver lifecycle coverage. Neither supplies the missing Honda non-replacement entry or project cleanup correlation.
