**CarPlay Screen winner: unknown.** The exact registration producer, callback table, comparator target, attached media sink, decoder, and final Display 0 Surface are not recovered. An earlier attempted live registry read was denied; no new live read, process memory access, or Honda operation is authorized here. The useful next evidence would be a hash-matched registration callgraph that resolves the concrete callback table or, if static analysis cannot, a separately reviewed lawful observation of the live registry. Neither is currently a supported extension API.

**Additivity result:** A second in-process screen registration joins a ranked *competition* and can replace/outrank stock; it does not create an independent consumer. A separate ClarityLink process cannot pass an address in its memory as a valid `jmcs` callback record. Thus this mechanism cannot currently preserve normal Type110 by design.
