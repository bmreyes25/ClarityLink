# Active-CarPlay decoder probe — offline measurement contract

Step 3 is **in progress**, and no new APK has been built or installed. The original approved decoder-capacity APK and its signed manifest remain historical evidence. It measured 28/30 frames from each of two NVIDIA decoders with CarPlay disconnected. That is 93.33%, below the new plan's 95% candidate gate; do not relabel it a pass. The old probe reports only aggregate counts/elapsed time and stops after EOS, so it cannot identify which output PTS were missing or measure output gaps.

The new diagnostic must leave factory CarPlay visible and allocate **one** extra 800×480 H.264 decoder at 15 fps for a bounded 60 seconds. It must not use an Activity that takes center foreground. It should record input and output presentation timestamps, monotonic arrival timestamps, format changes, EOS/drain, codec identity, and errors; output events must be tied to submitted input PTS. The first output is startup and excluded from the inter-output-gap gate. After the first output, no gap may exceed 250 ms. At least 95% of submitted frames must produce output after drain; for 30 inputs that requires **29**, and for a full 900-frame run it requires **855**. A codec error, missing EOS, incomplete 60-second input, or wrong format fails the decoder-only gate. A separate timed human observation must verify center CarPlay picture and spoken guidance before, during, and after; no trace can prove voice by itself.

`evaluate_trace.py` is a pure Mac-side scoring contract for JSONL events (`start`, `format`, `input`, `output`, `eos`, `error`). It intentionally returns the CarPlay picture/voice verdict as `UNOBSERVED`. Its tests cover the 28/30 failure, a 29/30 decoder-only pass, timing gaps, missing EOS, and unmatched output PTS. This is **not** a measured coexistence result; it defines what the future APK must log so a result can be scored without guessing. Resource cleanup, a no-permission manifest, exact APK hash, parked run card, and uninstall verification remain to be implemented before any car test.

Next offline task: implement a separate API-17 background-safe diagnostic package that emits this trace, then bench-test its lifecycle and sign/hash it. Do not modify the historical `decoder-capacity` package or install the candidate until its exact source, APK, run card, and rollback are reviewed.
