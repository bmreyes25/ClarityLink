The script writes only to `/mnt/usbdrive1/CLARITY_FORENSIC_<unique>/`. It binds the USB mount source, size, and serial/volume UUID to the fresh inventory before writing, then saves its exact reviewed manifest in the new sibling. It uses `.partial` while copying, checks expected length, hashes the closed file, journals the hash in `SHA256SUMS`, then renames it to its final name. It preserves tar errors. Tar listing confirms that the archive is readable as a tar; it **does not** prove that a live writable filesystem was copied atomically or completely. The script writes `STORAGE_DONE.txt`, **not** `FINISHED.txt`, because runtime snapshots and Mac verification remain.
