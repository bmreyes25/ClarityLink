# Historical C-P approval policy

This document name and any linked reviews are retained for historical C-P
records. They apply only to the original eight-phase, 135-command C-P profile
and do not authorize, constrain, or need to be copied into a new experiment.
The original approvals and consumed ledger are preserved unchanged.

For future work, use the concise
[risk-based experiment workflow](../safety/experiment-risk-levels.md) and
[vehicle-session rules](../safety/vehicle-testing.md). A fresh session decision
is still required for live work; review should match the risk rather than
repeat multiple engineering approval records. `safeForHonda() == false`.
