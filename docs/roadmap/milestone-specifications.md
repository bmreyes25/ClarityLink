# Milestone specifications

## CL-R1 — warning-preemption race

Construct a deterministic interleaving in which a frame is accepted and posted, then warning state changes before the UI runnable draws it. Identify the shared state boundary and make warning generation visible to dispatch. Drop/invalidate stale queued work and verify warning exit, renderer process death, repeated transitions, and resume. A queue acknowledgement is not draw evidence.

## CL-R2 — isolated API17 emulator

Resolve the unexpected target found by the private inventory without issuing commands to unknown targets. Establish a runner-owned emulator identity and ADB lifecycle, fail closed on any unexpected target, and prove the runner cannot affect a shared/user-owned server. Independent review precedes any rerun.

## CL-R3 — Binder-to-View completion

Run the final hashed APK on the approved isolated API17 emulator. Capture bounded static and changing frames, draw markers, warning rejection, lifecycle/recovery, resource closure, and a final artifact receipt. Keep aggregate memory and performance claims separate from per-frame payload bounds.

## CL-R4 — fixture-to-View

Connect the existing Type111 synthetic fixture decoder to the Binder frame contract and View. Test malformed input, timestamps, queue pressure, renderer teardown, and Type110 failure isolation. Label every input and output synthetic.

## CL-R5 — authenticated Type111 extension

Model the session boundary and failure policy from evidence. Require a genuine same-session authority contract before protocol implementation can be described as authenticated. Do not reuse another session's authorization or infer Honda behavior from another receiver.

## CL-R6–CL-R8 — Honda evidence, validation, and product target

First establish a supported output/admission contract and warning/lifecycle invariants. Then propose separately authorized, bounded hardware tests with exact stop and restoration criteria. Integrated navigation is the final acceptance target, not a current capability claim.
