# ClarityLink overview

ClarityLink is an experimental software and systems-research project. Its goal is to preserve stock CarPlay on the Honda Clarity center display while investigating a separate navigation stream for the cluster's existing Navigation region.

The vehicle feature is not implemented or validated. Current evidence supports only explicitly scoped static research, offline software, and partial isolated-lab work. Start with [current status](../status/current.md), then read the [architecture](../architecture/overview.md), [safety guide](../safety/vehicle-testing.md), and [roadmap](../roadmap/final-development-plan.md).

The project is not affiliated with Honda, Apple, Tesla, or another manufacturer. Its repository license has not been selected; see the [license decision](../project/license-decision.md).
