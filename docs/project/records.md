# Project records

These files serve different purposes and remain at their established paths because research reports and tools link to them.

| Record | Role |
|---|---|
| [`NEXT_ACTION.md`](../../NEXT_ACTION.md) | One immediate engineering action and its current gates. |
| [`PROJECT_STATE.md`](../../PROJECT_STATE.md) | Detailed rolling engineering ledger; historical entries remain below its current snapshot. |
| [`EVIDENCE_INDEX.md`](../../EVIDENCE_INDEX.md) | Claim-level provenance, evidence classification, and limits. |
| [`ROADMAP.md`](../../ROADMAP.md) | Higher-level project goal, workstreams, and future gates. |
| [`step-reports/`](../../step-reports/README.md) | Chronological milestone reports, including stops and negative results. |
| [`research/`](../../research/README.md) | Deep technical investigations, source analysis, and bounded plans. |

Use the README and [documentation hub](../README.md) first. A current summary links to, but does not replace or reinterpret, the detailed record.
