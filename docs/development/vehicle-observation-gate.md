# CL-OBS-01 — gated read-only observation

This campaign is conditional and is **not authorized** by CL-MASTER-01. Start only to answer a precise unresolved question from CL-IF-01 that preserved offline evidence cannot answer.

The proposal must name: question; evidence needed; why offline artifacts are insufficient; a fixed command allowlist; read-only rationale and side effects; identity and parked-state checks; privacy/retention; per-call timeout/output bounds; operator; stop conditions; post-observation factory checks; rollback; independent safety/security review; and exact owner approval.

Use no broad exploration. No install, process injection, private Binder command, CAN write, warning override, firmware change, or experimental receiver/Type111 session. If the allowed read cannot answer the question, do not run it. On mismatch, ambiguity, or unexpected state, stop immediately; do not add commands or retry under the same approval. Preserve raw captures only in authorized private storage and publish a sanitized result with limitations.
